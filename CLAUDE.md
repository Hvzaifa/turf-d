# Claude Code Instructions

The `design/` folder contains the official Claude Design export.

Treat it as the source of truth.

Rules:

- Never redesign the UI.
- Match spacing, typography and layout exactly.
- Build production-quality React + TypeScript components.
- Use Tailwind CSS.
- Keep components modular.
- Keep animations lightweight.
- Do not modify files inside `design/`.
- Reuse components whenever possible.
- Before completing any task, compare the implementation with the design and fix any visual differences.
